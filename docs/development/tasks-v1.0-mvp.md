## 2. 开发原则

- 本仓库为 Python 后端项目，优先服务微信小程序 MVP。
- 后端接口必须满足 `docs/api/frontend-contract-v1.0-mvp.md`。
- 路由层只处理 HTTP 入参、鉴权、调用 service 和返回响应。
- 业务编排放在 `services/`。
- 数据库读写放在 `repositories/`。
- Pydantic 入参、出参和内部结构放在 `schemas/`。
- 配置、异常、日志、响应包装、依赖注入放在 `core/`。
- 图片校验、SHA256、时间格式化等通用逻辑放在 `utils/`。
- AI 调用只允许发生在后端。
- 所有医疗相关文案必须避免诊断、治疗、处方等高风险表达。
