# AI宠物健康分析微信小程序

## MVP 产品需求文档（PRD V1.0）

---

# 1. 项目概述

## 1.1 项目名称

AI宠物健康分析助手（暂定）

---

## 1.2 项目背景

当前越来越多宠物主人开始关注宠物日常健康问题，但普遍存在：

- 无法判断宠物异常是否严重
- 去宠物医院成本较高
- 缺少基础健康知识
- 新手养宠焦虑严重
- 缺少长期健康记录工具

AI大模型已具备基础图片识别与文本分析能力，可用于宠物日常健康辅助分析。

因此，本项目计划开发一款：

> 面向普通宠物用户的 AI 健康分析微信小程序。

---

## 1.3 产品定位

本产品定位：

# AI宠物健康管理工具

产品目标：

- 提供日常健康参考
- 提供风险提醒
- 帮助用户判断是否需要观察或就医

本产品不是：

- 在线兽医平台
- 医疗诊断系统
- 医疗治疗平台

---

# 3. 用户分析

---

## 3.1 目标用户

核心用户：

20~35岁养猫、养狗用户。

---

## 3.2 用户特征

用户通常：

- 高频使用微信
- 喜欢小红书内容
- 愿意尝试AI产品
- 对宠物健康敏感
- 有分享欲

---

## 3.3 用户痛点

|用户问题|当前情况|
|---|---|
|不知道是否严重|缺少基础判断能力|
|去医院成本高|不愿频繁检查|
|网上信息复杂|难辨真假|
|新手经验不足|焦虑严重|
|无法长期记录|缺少工具|

# 5.2 AI便便健康分析（核心功能）

---

## 功能说明

用户上传宠物便便照片后，系统调用AI进行健康分析。

---

## 功能目标

帮助用户：

- 判断是否异常
- 判断风险等级
- 判断是否建议观察或就医

---

## 用户流程

```
上传图片→ AI分析→ 返回结果
```

---

## 输入内容

---

### 必填

- 图片

---

### 可选

- 猫/狗
- 宠物昵称

---

## 图片上传要求

支持：

- 拍照
- 相册选择

---

## 图片限制

|项目|限制|
|---|---|
|格式|JPG / PNG|
|大小|≤10MB|

上传后自动压缩。

---

## AI分析结果

---

### 健康评分

范围：

1~100分

例如：

```
82分
```

---

### 风险等级

包括：

- 低风险
- 中风险
- 高风险

---

### AI分析总结

例如：

```
轻微软便建议观察饮食状态
```

---

### 是否建议就医

例如：

```
若持续48小时建议线下就医
```

---

## AI输出格式

AI必须返回结构化JSON。

例如：

```
{  \"score\": 82,  \"risk\": \"低风险\",  \"summary\": \"轻微软便\",  \"suggestion\": \"建议观察饮食状态\"}
```

---

## 功能限制（重要）

系统禁止：

- 疾病诊断
- 药物建议
- 医疗结论

---

## 异常提示

---

### 上传失败

提示：

```
图片上传失败，请重试
```

---

### AI分析失败

提示：

```
当前分析人数较多，请稍后再试
```

---

## 功能优先级

P0

# 6. AI调用与成本控制

---

# 6.1 AI调用规则

不是所有请求都调用AI。

只有：

```
未命中缓存
```

时才调用大模型。

---

# 6.2 图片缓存机制（必须）

---

## 缓存流程

```
上传图片→ 生成图片SHA256→ 查询数据库→ 命中缓存→ 直接返回历史结果
```

---

## 缓存目标

避免：

- 重复分析
- 重复上传
- 恶意刷接口

---

# 6.3 用户次数限制

---

## 游客用户

每天：

```
3次
```

---

## 登录用户

每天：

```
10次
```

---

# 6.4 请求限流

---

## 分析间隔

每次分析间隔：

```
10秒
```

---

# 6.5 图片压缩

上传后：

自动压缩图片。

目标：

降低AI图片分析成本。
